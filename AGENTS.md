# Panopticon Generative AI rules

## Guidelines
 - Always use types in the language syntax where available.
 - Every function should have an appropriate docstring following the template below:

```
[FUNCTION DESCRIPTION]

Args:
    [ARG NAME] ([ARG TYPE]): [SHORT DESCRIPTION]

Returns:
    [TYPE]: [SHORT DESCRIPTION]
```

 - Ensure appropriate tests are written for functions, integrations or services that require them.
